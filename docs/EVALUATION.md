# 历史效果与公开版验证

本仓库是企业报价项目的脱敏公开版。原始企业目录、单据、客户资料和评测附件不随仓库发布。

## 作者确认的历史业务测试结果

| 数据类型 | 字段正确率 |
| --- | ---: |
| 非手写单据 | 100% |
| 手写单据 | 90% |

以上结果由作者提供，并于 2026-11-05 确认按字段统计。当前找到的历史记录覆盖不同日期、模型、输入方式和字段范围，尚不能复算这两个汇总值的完整分子、分母、样本量与具体测试批次；不将其写为独立复核或本公开版重新测得的结果。

字段正确率不能替代整张单据全部正确、产品身份确认、价格准确率或生产验收。留空、漏行、歧义与提前选定候选需要分别评价。

## 本公开版可以复现的内容

`scripts/create_demo_data.py` 从代码生成虚构目录；离线演示回放固定合成提案，复用确认、匹配、计价、PDF/PNG 输出。回归测试使用模拟 OCR/API，验证软件行为与失败门禁。它们不能测出真实模型的字段正确率。

本轮实际测试命令、安装与出单结果见 [验证记录](VALIDATION.md)，API 配置见 [README](../README.md#真实-ai-识别可选)。
