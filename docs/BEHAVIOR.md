# 公开演示版行为合同

本文件约束公开版的演示行为，不代表任何企业的实际商品或业务规则。示例关系与数值全部虚构。

## 输入、模型与人工确认

- 支持文字、TXT、XLSX、PDF、静态图片。旧 XLS 读取依赖未包含，失败时提示另存为 XLSX；多帧图片要求拆分，不静默只处理首帧。
- 图片先在本地 OCR；PDF 文字层与同页 OCR 作为互补证据，不直接算成两份订单。
- 上传预览与 OCR 共用静态图片验证：仅 PNG、JPEG、WebP、BMP，原始像素不超过 2400 万，规范化长边不超过 2400。PDF 最多 20 页，渲染前限制长边 2400、累计像素 2400 万；超限拒绝整个来源，不静默截断。
- 模型只能提出分类、品名、规格、箱数、等级和候选，并引用原始输入。不可补价格、包装、重量或修改主数据。
- 五列确认表只显示分类、产品名、规格、箱数、等级。原始字段、位置、警告和候选保留在内部与证据区域。
- 分类允许沟槽、玛钢、球铁。物理玛钢表中的球铁 / 球热前缀商品属于球铁 UI 范围，不能同时当作普通玛钢商品。
- 正常无等级的条目默认 `b`；`a` / `A` / `b` 区分，黑 / 黑袋 / 中按演示约定映射 `a`，蓝 / 蓝袋 / 好映射 `b`。未知、冲突和待核对等级不得套用默认值。
- 标题上下文按来源、页、读取方式与列限定；不能将一列或一页的等级传播到另一处。
- 人工确认后才能查价；再次编辑确认字段使旧确认和价格失效。模型提案通过结构检查不等于准确识别。
- 失败占位由核心确认函数阻断，填满五列也不能确认；用户可删除占位后明确新增独立人工记录。

## 主数据与匹配

- `主数据/` 根层恰好一张非临时 XLSX；`~$` 锁文件不参与选择。
- 工作表依次为沟槽数据、玛钢数据、等级映射；产品表包含分类、源代码、商标、品名、规格、别名、价格标记、轻重、单价、包装数、毛坯单重、成品单重、纯毛单重、启用状态、记录键、备注。
- 工作簿分类 + 正式品名 + 规格 + 档位构成唯一业务键。非法字段、重复键、缺失必要说明或没有可检索记录时阻断加载。
- 产品唯一匹配、合法别名目标、分类范围和档位必须一致。不存在目标档位时不回退；有实质差异的多候选不自动选择。
- `待补充` 价格行保留可见但不计价、不导出；整单均无价时不生成空单。
- 主表内容 SHA-256 随匹配保存，预览、输出前和最终回读后重新核验。变化时旧价格失效；本次已创建的输出回滚。

## 金额与输出

- 件按箱处理；箱数和非空包装数必须为正整数；单价必须是有限正数。
- 行金额 = 箱数 × 每箱个数 × 每个单价，用 `Decimal` 和 `ROUND_CEILING` 逐行取两位小数，再汇总。
- 缺包装时保留商品行，包装、总个数、行金额为空；汇总只显示已计算小计，不宣称完整总计。不得人工猜包装。
- 演示销售单使用匿名标题“示例企业销售单 - 虚构数据”。规格保留 `a` / `A` 后缀，`b` 不加后缀；重量口径未定义，始终留空。
- 输出编号为随机 `QA-XXXXX-XXXXX`，排除易混淆字符；PDF 与逐页 PNG 均排他写入，不能覆盖已有文件。
- 单位名称必须先确定；预览只在内存生成，不持久化名称和报价记录。
- 最终文件成功创建、回读和核验后，排他写入本地报价记录，再原子保存名称历史。失败回滚仅限本次创建文件。
- 刷新可以丢失草稿；已生成的历史文件不能作为修改后新报价的有效结果。

## 本地运行边界

默认监听 `127.0.0.1`。不提供公网认证、多用户隔离、多进程事务和实时 OCR 中断。运行目录保存输入和诊断，不能加入公开仓库。公开版的发布清单只允许审核后的源码、合成测试和文档资产。

OCR 资源缓存只保留一份主表版本，避免更新主表后累积模型实例。真实 Paddle 内存释放与硬件表现仍需在目标 OCR 环境实测。
