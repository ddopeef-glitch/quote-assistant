## 九项问题的修复范围

1. **图片依赖与输入安全**：升级为 Streamlit 1.66.1、Pillow 13.0.0、Starlette 1.10.0。Pillow 的相关解析修复见 [官方 13.0.0 说明](https://github.com/python-pillow/Pillow/blob/main/docs/releasenotes/13.0.0.rst)；Streamlit 兼容范围核对了 [1.66.1 包元数据](https://pypi.org/project/streamlit/1.66.1/)。统一真实格式验证、像素上限与多帧拒绝，保留媒体响应回归。
2. **新建数据回归**：冻结夹具只比较稳定业务字段，当前快照的目录 ID 与主表指纹单独验证。两份独立生成工作簿业务一致、ID 随指纹变化；保留旧提案失效规则。
3. **PDF 渲染限额**：两条读取入口共用渲染函数，在分配前限制页数、尺寸和累计像素；缺 OCR 不先渲染。覆盖异常大页面及正常图文互补。
4. **规格一致性**：目录投影复用核心规范化；`x`、`×`、`*`、`-` 均可用，原始字段仍保留。
5. **发布路径**：业务目录大小写不敏感，拒绝 `.env`、环境变体与 Streamlit 秘密配置，仅保留 `.env.example`；现有哈希、链接与凭据检查保持。
6. **预览异常恢复**：先验证再预览；损坏、动图和伪装格式只产生文件级提示，不使页面崩溃，不调用 OCR/API。
7. **失败占位门禁**：核心确认函数拒绝填满五列的失败占位；删除占位后明确人工新增仍可用。
8. **OCR 生命周期**：资源缓存只保留一个主表版本；五次指纹变化的假模型弱引用测试证明旧实例不被缓存保留，清缓存后全部释放。
9. **代码精简**：删除无调用入口及无效常量，可选重量复用正数校验。应用与脚本共增加 74 行、删除 87 行，净减少 13 行，未新增运行依赖或框架。

升级引起的 AppTest 文件路径与 Session State 接口变化均已适配，所有原有业务断言继续执行。发布清单在审阅源码、测试、文档和合成图片后更新；历史 ZIP 保留，修复版单独打包。
